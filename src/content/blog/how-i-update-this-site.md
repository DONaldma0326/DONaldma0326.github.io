Keeping this site simple was important, so I use a file-based workflow:

1. Add or edit Markdown in `src/content/projects` or `src/content/blog`.
2. Run `npm run dev` locally to preview changes.
3. Commit and push to GitHub.
4. GitHub Actions builds and deploys automatically.

This keeps content updates fast and free.
